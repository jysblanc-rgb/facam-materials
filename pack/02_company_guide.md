# 모아공방 회사 설명서 (연습용 가상 회사)

이 문서는 연습용으로 만든 가짜 회사 「모아공방」의 설명서예요. 실제 회사나 사람과 관계가 없어요.

## 우리 회사는 이런 곳이에요
- 하는 일: 면, 린넨, 캔버스 천으로 앞치마, 파우치, 토트백을 만들어 팔아요.
- 직원: 대표 1명, 직원 2명 (주문·배송 담당 1명, 생산·재고 담당 1명)
- 파는 곳: 자사몰, 스마트스토어, 카카오톡 채널, 인스타그램 DM

## 상품과 가격
| 상품 | 가격(원) | 비고 |
|---|---|---|
| 린넨 앞치마 (베이지, 그레이) | 32,000 | 기본 상품 |
| 캔버스 토트백 | 28,000 | 10개 이상이면 개당 26,000 |
| 면 파우치 소 | 9,000 | |
| 면 파우치 대 | 12,000 | |

## 주문부터 배송까지 순서
1. 주문이 들어오면 주문 채널별로 받은 내용을 주문 엑셀에 옮겨 적어요.
2. 재고를 확인해요. 재고가 모자라면 부자재와 원단을 발주해요.
3. 평일 오후 3시까지 결제가 끝난 주문은 그날 포장해서 택배사에 접수해요.
4. 송장 번호가 나오면 고객에게 알려요.

## 문의 답변 기준
- 배송: 결제 후 평일 기준 2~3일 안에 도착해요. 송장 번호는 출고 당일 알려요.
- 교환: 상품을 받은 날부터 7일 이내에 가능하고, 왕복 배송비는 고객이 내요. 상품에 문제가 있을 때는 우리가 내요.
- 환불: 상품을 확인한 뒤 진행해요. 색이나 모양이 사진과 다르다는 문의는 대표가 직접 확인해요.
- 단체 주문: 캔버스 토트백은 10개 이상이면 개당 26,000원이에요.
- 해외 배송: 현재는 국내만 가능해요.
- 세금계산서: 사업자 정보를 보내 주시면 발행해 드려요.
- 로고 제작 등 정해지지 않은 문의는 대표에게 물어본 뒤 답해요.

## 하루 일과
- 오전: 발주, 미팅(주 2~3번)
- 오후: 주문 확인, 문의 답장, 택배 접수, 정산
- 금요일: 다음 주 생산 계획, 카드 매출 정리

## 우리가 불편한 점
- 주문이 채널마다 따로 들어와서 엑셀에 손으로 옮겨 적어요.
- 같은 문의가 반복되는데 매번 처음부터 답장을 써요.
- 금요일마다 카드 매출을 정리하는 데 50분쯤 걸려요.
